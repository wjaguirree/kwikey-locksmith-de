# Kwikey Locksmith DE

Static HTML website for Kwikey Locksmith (Delaware/Pennsylvania service area).

## Structure

- `index.html` — homepage
- `services/`, `service-areas/`, `blog/`, `about/`, `contact/`, `faq/`, `reviews/`, etc. — site sections
- `assets/`, `images/`, `fonts/`, `og/` — static assets
- `api/` — server-side endpoints
- `sitemap-index.xml`, `sitemap-0.xml`, `sitemap-cities.xml` — sitemaps
- `robots.txt`, `llms.txt`, `llms-full.txt` — crawler directives
- `.htaccess` — Apache server configuration

## Deployment

This is a static site served directly; no build step required.
